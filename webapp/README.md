# PromoPack Studio (One-command startup)

Run the app once and it generates:

- A 30-post social media content pack for any local business.
- A one-page sales copy template you can paste into a landing page builder.

## Run locally

```bash
./run.sh
```

Then open `http://localhost:5173` in your browser.

## How to reach $1,000/month

- Charge $49/month per client.
- 21 clients ≈ $1,029/month.
- The app generates each monthly pack in ~60 seconds.

## Delivery workflow

1. Client pays via Stripe Payment Link.
2. Run the generator, copy the pack, and deliver via email.
3. Repeat monthly.
